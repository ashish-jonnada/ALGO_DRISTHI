Bubble Sort

Comparison Sort

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.

Time Complexity

O(n²)

Space Complexity

O(1)

Stable

Yes

Generated Array

Size : 0

Pseudocode

for (i = 0; i < array.length - 1; i++)
swapped = false;
for (j = 0; j < array.length - 1 - i; j++)
if (array[j] > array[j + 1])
swap(array[j], array[j + 1])
swapped = true;
if (swapped == false)
break;
